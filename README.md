# Scheduler Assistant

This scheduling assistant will take in the contents of a Beaverton season schedule from `compumetrics` and generate a downloadable Calendar with location information filled.

### Published to the following location:

https://soccer.mirthandmalice.co/

# Usage

<img width="1497" height="462" alt="soccer-helper-empty" src="https://github.com/user-attachments/assets/4ee5e7c1-097e-46a9-9834-bc6ee201c82d" />


- Go to the `soccer schedule` page from `mirthandmalice` (https://soccer.mirthandmalice.co/)
- Open `compumetrics` (https://schedules.compumetics.com/)
- Click through any information/disclaimers regarding soccer conduct
- Find Team
- Select All from this Page
- Paste into field on the `soccer scheduler`
- Submit

You should get a chart of every game in the season.
From this either download the calendar for the entire season or individually.

# Disclaimers

I didn't write or generate any of the raw schedule information.  I'm also not associated with any of the Beaverton Rec teams.
If for some reason the format changes in a breaking way this may stop generating schedules.
This is just a best-effort project to make it easier to pull a season schedule into a google/apple calendar so parents are less likely to miss games or get confused.
